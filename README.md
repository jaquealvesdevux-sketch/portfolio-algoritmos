# Algoritmos em Portugol

Este repositório contém exercícios e algoritmos desenvolvidos em **Portugol**, com foco no **aprendizado de lógica de programação** e no desenvolvimento do raciocínio computacional.

O objetivo deste projeto é registrar minha evolução nos fundamentos da programação antes da migração para linguagens de mercado, como **PHP** e **JavaScript**.

---

## Objetivo do Projeto

- Praticar lógica de programação
- Compreender estruturas fundamentais:
  - Condicionais (`se`, `senao`)
  - Laços de repetição (`enquanto`, `para`)
  - Variáveis e entrada/saída de dados
- Desenvolver pensamento lógico e organizado para resolução de problemas

---

## Conteúdos Abordados

- Algoritmos básicos
- Estruturas condicionais
- Estruturas de repetição
- Exercícios matemáticos e lógicos
- Resolução de problemas simples passo a passo

---

## Observações Importantes

- Este projeto **não tem foco em produção ou mercado**, mas sim em **fundamentos**
- Portugol foi utilizado como linguagem didática para facilitar o entendimento da lógica
- Os algoritmos aqui podem servir como base para reescrita em outras linguagens

- Criar versões comentadas dos algoritmos
